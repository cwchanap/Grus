## Implementation strategy — three green commits, one PR

Implement as **three reviewable commits**, each a **complete runnable Rust + Godot slice** with fmt, Clippy, Rust tests, 90% sim coverage, four Godot smokes, exported boot/e2e and the 10-second benchmark passing **before proceeding**. Do not commit half a Rust-enum migration with failing CI. This staged approach does **not** add backwards-compatibility aliases or dual code paths: the temporary names between checkpoints are the still-current model until the next committed rename. Re-run the matrix at the final PR head. Keeping geometry fixed until checkpoint 3 distinguishes an API/string failure from a movement/pathing regression.

1. **Delete obsolete PvP systems (green checkpoint 1):** keep the *existing* Food/Wood/Gold + Villager/Spearman/Archer/TownCenter/House/Storehouse/Barracks names/positions temporarily, but delete Age, AgeUp, Farm, ArcheryRange, Stable, Cavalry and `FarmOccupied`; let Barracks train Spearman **and** Archer; set obsolete PvP counter bonuses to zero. Change the scripted benchmark extras to 16 Villagers/40 Spearmen/40 Archers, and rewrite the obsolete Age/Farm/Cavalry smoke legs as meaningful remaining economy/build/production proofs. Adjust GDScript reject integers, old Rust tests and documentation for this checkpoint. **Run and record the full matrix.**
2. **Rename catalogue and public wire (green checkpoint 2):** change resources to Food/Scrap/Coal plus **stockpile-only Crystals**, units to Worker/Guard/Rifleman, buildings to ResearchCenter/Bunkhouse/Depot/Barracks and costs/stocks to **200/300/150/0**. Add the atomic shared spend helpers below. Migrate every Rust, bridge, scene, smoke and documentation reference without touching fixture positions; all old test waypoints remain valid at this stage. **Run and record the full matrix.**
3. **Re-author layout/presentation (green checkpoint 3):** relocate Team-1 city and resource nodes, keep Team-2 passive east, remove PvP blockers, add a single-source ruin table rendered from bridge data, centralize TeamStart anchors/source membership, retire duplicate spawn fields, and adapt smoke waypoints/camera and the benchmark safe-source mapping. **Run and record the full matrix again**, including geometry, camera framing and the active 200-unit workload.
