## Updated review decisions (GitHub design review)

- **Sourcing locked:** `scripts/build_sfx_assets.py` generates the original sound designs offline with deterministic Python waveform/noise/envelope synthesis (no paid API); a documented **one-pass ffmpeg** trim/edge-cleanup/loudness-normalization/OGG export creates final assets. The generator is authoring-only, not a runtime or CI pipeline. Capture seed, command and processing options in `godot/assets/audio/README.md`.
- **Audio format:** 18 final OGG Vorbis files only, exact filenames from the [design inventory](../specs/2026-11-07-hpa-269-survival-sfx-design.md#asset-inventory-18-original-audio-files). No WAV branch or alternative paths.
- **Mixer:** one `const CUES` table with `preload()`, `volume_db` and `max_polyphony` for each cue; construct one `AudioStreamPlayer` per cue at startup. Use Godot's built-in polyphony (combat 2 initially, alerts/wind/outcomes 1) and a 150 ms **per-cue** combat throttle. No recycled-voice pool, per-frame quota, bus/ducking or priority engine.
- **Identity:** at the start of `_process()`, **unconditionally scan** unit/building view groups once per rendered frame into current ID→kind dictionaries, *before* `_refresh_session()` can return early in Start/Paused/Result. Resolve present attackers from current; resolve killed alien targets from current or previous maps; replace previous maps **after** `_refresh_session()` on every phase. Keep the existing live-view lookup for tracers. No growing cache, pruning or extra per-event audio scans. Hidden attacker IDs scrubbed to 0 stay silent.
- **Integrity:** final `const CUES` uses **18 static `preload()` values**, so missing files fail at script load. A known supported **attacker** missing its attack cue or a killed **alien** missing its death cue invokes `push_error()`. **Do not attempt a death cue for friendly units or buildings**: their deaths are silent and not mapping errors. Unknown/scrubbed attacker identities are silent. Verify 18 non-null streams and supported attack/four alien-death mappings in **one existing smoke**.
- **Transition state:** horns re-arm whenever `incoming_zones` is empty; cold state updates on every frame regardless of phase but only sounds on Playing warm→cold; **wind's preloaded `AudioStreamOggVorbis.loop = true` is set explicitly at initialization** (cue-table `loop` flag), then playback follows the current phase; Result uses existing `result_frame`. These heal after `GrusBridge.reset_fixture()` even when the controller restart helper was skipped.
- **Listening gates:** two explicit **human approvals**, not assumptions made by a headless runner. When the three-clip pilot is ready, stop for human feedback before producing the remaining 15. After full implementation, stop for a real listening verdict before marking PR ready.
- **Verification:** `CombatFx.clear_all()` also clears test-only `cue_counts` and per-cue throttle timestamps. Direct bridge fixture resets **do not** invoke it: smoke checks use per-checkpoint baseline/delta counters, exact `+1` per alert/Result edge, and positive rather than exact counts for combat at 20× speed. CI is the canonical smoke runner; it checks **both expected marker and exit 0 under timeouts**. No exit-only local loop or unnecessary local Rust Clippy/coverage reruns.

## Checkpoint 1 — Generate and wire the three-sound prototype

**Files:** `scripts/build_sfx_assets.py`, `godot/assets/audio/{combat,ambience}/`, `godot/assets/audio/README.md`, `godot/scripts/{combat_fx,battlefield_controller}.gd`, relevant existing smoke.

- [ ] Author a small deterministic **offline Python source script** using standard-library synthesis (seeded noise, filtered layers, pitch sweeps, envelopes, simple resonances). Start with Gun Turret fire, Swarmer death and loopable winter wind. Prefer clear readable game sounds over complicated synthesis models; use the exact final `.ogg` filenames. In the cue table mark only the wind entry as `loop = true`, and in `CombatFx._ready()` assign `(stream as AudioStreamOggVorbis).loop = true` before wiring the player.
- [ ] Add a **single documented ffmpeg normalization/cleanup/OGG encoding pass** for generated temporary PCM files, including trim/edge smoothing, target loudness and peak ceiling. Wind needs a seam-matched/crossfaded loop without a level dip. Record exact invocation and settings in audio README. Keep runtime/CI independent of ffmpeg and the Python script.
- [ ] Implement the tiny `CombatFx` cue-table/player approach **with these three pilot entries**, including `volume_db`, native `max_polyphony`, wind `loop`, a 150 ms *wall-clock* per-cue throttle and a `cue_counts` hook incremented after a successful play request. `clear_all()` stops players, clears `cue_counts` and resets throttle timestamps (but not snapshot-based warning/Result state). Route Gun Turret fire, known Swarmer death and session-dependent wind through **real** `battlefield_controller.gd` event/phase paths. Keep current hit/death meshes. During the intentionally partial pilot, other sounds can temporarily retain the old generic blip; remove it when the full cue table arrives. Never silently ship a missing supported kind in the final implementation.
- [ ] Extend the existing appropriate smoke(s) to require all three pilot streams, their real event-path routing and core gameplay outcomes. **Run the existing CI smoke gates green** at this checkpoint; do not add a temporary harness or new smoke scene.
- [ ] Do not mark full 18-stream completeness at this stage. The three-clip smoke assertions become 18-stream assertions in Checkpoint 3.

- [ ] Replace the pilot's partial table with exactly **18 `preload()` entries**. Remove `_make_blip()` and any temporary generic fallback. Death of Worker/Guard/Rifleman or any building produces no death sound and **no `push_error()`**. ## Checkpoint 4 — Wave, cold, lifecycle edges and existing journey tests

**Files:** `godot/scripts/{combat_fx,battlefield_controller}.gd`, existing `wave_smoke_test.gd`, `economy_smoke_test.gd`, `combat_lifecycle_smoke_test.gd`, `defenses_smoke_test.gd`.

- [ ] From the **existing** `wave_snapshot()` in `_refresh_hud()`, clear `_horn_wave` on every empty `incoming_zones` snapshot (including Start and Paused); play once on the first nonempty warning for a different `next_wave` while Playing. Neither repeated frames, minimap ping expiry nor multiple announced zones trigger extras.
- [ ] From the **same** `economy_snapshot().surface_efficiency` used for the HUD cold icon, compute `cold = surface < 1.0` every frame in every phase; play once only on a Playing transition from warm to cold. Update `_was_cold` unconditionally, so a reset to warm (including direct `GrusBridge.reset_fixture()`) and full recovery re-arm it.
- [ ] Drive the quiet wind player's play/pause/stop directly from `session_snapshot().phase` on every frame. Use the already-computed `result_frame` to play one Victory or Defeat stinger **after** the settle-tick combat-event drain; don't stop/duck the killing-blow sound.
- [ ] `clear_all()` retains visual cleanup, stops live sound players and clears test telemetry `cue_counts` plus per-cue throttle timestamps; do **not** depend on it for logical wave/cold/Result flags. Direct `GrusBridge.reset_fixture()` does not call this hook, so test telemetry need not reset on that path. Build current unit/building kind dictionaries at the start of **every `_process()`**, not behind `_refresh_session()`'s Playing/Result early return, and advance previous maps after event dispatch unconditionally. This preserves first-tick kill resolution and heals across reseeds.
- [ ] Reuse `wave_smoke_test.gd`'s authored incoming warning to check **exactly +1 horn per transition** relative to a recorded count baseline. Reuse `economy_smoke_test.gd`'s existing heat deficit/recovery **across its direct fixture reset**, recording a new baseline for each leg, checking **exactly +1 cold cue per warm→cold edge** and zero extras while cold. Use `combat_lifecycle_smoke_test.gd` for paused silence, alien-only death routing, **exactly +1 Result stinger**, and restart cleanup; `defenses_smoke_test.gd` for the Gun Turret tracer and **a positive increase** in turret cue count. Never assert an exact count of combat strikes at 20× speed: throttling follows `Time.get_ticks_msec()` and depends on runner load. Preserve all real journey checks and success markers.
- [ ] Assertions inspect the `cue_counts` hook and loaded cue table, not headset-dependent `is_playing()` (headless Godot's Dummy driver cannot prove audible playback). After `clear_all()` counts restart from zero; **across direct fixture resets** compare captured before/after deltas rather than absolute values. Each count represents an actual playback request *after* per-cue throttle. Check built-in wind `loop=true`, not audible seam quality (human listening gate).
