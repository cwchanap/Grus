# Structure models (HPA-291)

Low-poly GLB art for `building_view` models, generated by
`scripts/build_winter_assets.py` (run Blender with `--python-exit-code 1`).

Naming contract: `building_view.gd` derives each kind's model path as
`res://assets/structures/<building_kind>.to_snake_case() + ".glb"`, reusing
the catalogue `buildings` keys — e.g. `Bunkhouse` → `bunkhouse.glb`,
`GunTurret` → `gun_turret.glb`. An unfinished building shows
`construction_site.glb` until the bridge pushes `complete`.

Every structure mesh is authored against the normalized ±0.5 footprint
(`export()` divides authored horizontal extents by the catalogue
footprint) with a grounded base, under 4,000 triangles, tinted by COLOR_0
vertex colors over the shared `structure_albedo.png` grain — the same
recipe the winter props use via `winter_glb_import.gd`. Imported models
are presentation-only: no physics, collision, navigation or occluder
nodes.

Committed so far (pilot): `construction_site.glb`, `bunkhouse.glb`,
`structure_albedo.png`, `ice_overlay.tres` (the single pale translucent
overlay material views assign to `material_overlay` while Rust reports a
building cold). The remaining catalogue kinds land in the next
checkpoint; completed views fall back to a code-authored placeholder
until then.
