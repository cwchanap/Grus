# Structure art (HPA-291 / HPA-697)

Eight finished building kinds render the painted PNG sprites under
`painted/` (one shared `painted/construction_site.png` for every
unfinished building); they are authored art copied from
`art-src/2026-11-09/sprites/`, not generator output. Only the two
1×1 seam/corridor kinds keep low-poly GLB models, generated by
`scripts/build_winter_assets.py` (run Blender with `--python-exit-code 1`).

Naming contract: `building_view.gd` preloads `painted/<kind>.png` keyed by
catalogue building kind in snake case — e.g. `Bunkhouse` →
`painted/bunkhouse.png` — and a `MODELS` map with the retained GLBs:
`Wall` → `wall.glb`, `Gate` → `gate.glb`. An unfinished building shows the
shared site sprite until the bridge pushes `complete`; a completed Wall or
Gate swaps to its GLB. Cold is a reversible `Sprite3D.modulate` tint on
sprite kinds — Wall/Gate GLBs never take it and no overlay material exists.

| Asset | Triangles | Footprint | Use |
| --- | ---: | --- | --- |
| `wall.glb` | 228 | 1x1 | Four-side barricade; band and rail reach every edge |
| `gate.glb` | 276 | 1x1 | Corner-pier portal frame with high ring beam |

Both GLBs are authored at their true 1×1 catalogue footprint in Blender
world units (`export()` divides authored horizontal extents by the
footprint), exported into the normalized ±0.5 cell with a grounded base,
under 4,000 triangles, tinted by COLOR_0 vertex colors over the shared
`structure_albedo.png` grain. Wall and Gate meet neighboring tiles at
±0.5 in either axis, so straight and Wall–Gate–Wall runs read continuous
without rotations or neighbor masks. Imported models are
presentation-only: no physics, collision, navigation or occluder nodes.

Also committed: `structure_albedo.png` (the generated 64x64 neutral grain
both GLBs reference).

Models were authored for this repository using [the Blender
source](../../../scripts/build_winter_assets.py), exported with Blender
5.2.1 LTS. To regenerate from the repository root (the same run also
refreshes the winter props under `assets/winter/`):

```sh
blender --background --factory-startup --python-exit-code 1 --python scripts/build_winter_assets.py
```

`--python-exit-code 1` makes a failed export check fail the whole
command instead of leaving a mixed stale/fresh GLB set under a success
status. Each GLB is validated before it replaces the previous file; the
exporter checks bounds, triangle budgets and external texture references. Commit the
`.glb.import` and PNG `.import` settings; Godot recreates the ignored
`.godot/` cache.
