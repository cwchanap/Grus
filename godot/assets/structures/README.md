# Structure models (HPA-291)

Low-poly GLB art for `building_view` models, generated by
`scripts/build_winter_assets.py` (run Blender with `--python-exit-code 1`).

Naming contract: `building_view.gd` preloads a `MODELS` map keyed by
catalogue building kind; filenames use snake case — e.g. `Bunkhouse` →
`bunkhouse.glb`, `GunTurret` → `gun_turret.glb`. An unfinished building shows
`construction_site.glb` until the bridge pushes `complete`.

| Asset | Triangles | Footprint | Use |
| --- | ---: | --- | --- |
| `research_center.glb` | 314 | 4x4 | Central laboratory, stepped lab tower, cyan window band and research mast |
| `bunkhouse.glb` | 208 | 2x2 | Heated bunk cabin with stove annex and warm windows |
| `depot.glb` | 240 | 2x2 | Open-sided cargo shelter, stacked crates and drum |
| `barracks.glb` | 344 | 3x3 | Broad fortified hall with roof and corner blocks |
| `wall.glb` | 228 | 1x1 | Four-side barricade; band and rail reach every edge |
| `gate.glb` | 276 | 1x1 | Corner-pier portal frame with high ring beam |
| `gun_turret.glb` | 308 | 2x2 | Squat drum, front shield and long barrel |
| `coal_furnace.glb` | 288 | 2x2 | Iron body, tall round chimney and glowing heat vent |
| `flame_tower.glb` | 380 | 2x2 | Fuel-drum cluster and a short fat nozzle |
| `crystal_lance.glb` | 220 | 2x2 | Tall slender cyan emitter with leaning shards |
| `construction_site.glb` | 208 | 1x1 normalized | Fenced foundation, scaffold and unfinished framing |

Every structure mesh is authored at its true catalogue footprint in
Blender world units (`export()` divides authored horizontal extents by
the footprint, so round chimneys and barrels stay round under the
view's root scale), exported into the normalized ±0.5 cell with a
grounded base, under 4,000 triangles, tinted by COLOR_0 vertex colors
over the shared `structure_albedo.png` grain — the same recipe the
winter props use via `winter_glb_import.gd`. Wall and Gate meet
neighboring tiles at ±0.5 in either axis, so straight and Wall–Gate–Wall
runs read continuous without rotations or neighbor masks. Imported
models are presentation-only: no physics, collision, navigation or
occluder nodes.

Also committed: `structure_albedo.png` (the generated 64x64 neutral
grain every GLB references) and `ice_overlay.tres` (the single pale
translucent overlay material views assign to `material_overlay` while
Rust reports a building cold).

Models were authored for this repository using [the Blender
source](../../../scripts/build_winter_assets.py), exported with Blender
5.2.1 LTS. To regenerate from the repository root:

```sh
blender --background --factory-startup --python-exit-code 1 --python scripts/build_winter_assets.py
```

`--python-exit-code 1` makes a failed export check fail the whole
command instead of leaving a mixed stale/fresh GLB set under a success
status. Each GLB is validated before it replaces the previous file; the
exporter checks bounds, triangle budgets and external texture references. Commit the
`.glb.import` and PNG `.import` settings; Godot recreates the ignored
`.godot/` cache.
